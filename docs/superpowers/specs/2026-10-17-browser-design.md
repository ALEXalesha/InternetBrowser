# InternetBrowser - описание замысла

Дата: 17.10.2026. Описание - Claude по ответам Алексея. Статус: ждёт «да».
Репозиторий Gitea `ALEXaloysha/InternerBrowser` (в имени опечатка - переименовать в InternetBrowser вместе с GitHub по «да»).

## Что это и зачем
Свой браузер-**витрина**: красивый, без рекламы и слежки, для своих проектов и для показа.
Не замена Chrome на каждый день (решение Алексея: «витрина/демо»), поэтому не гонимся за совместимостью и скоростью Chrome
во всём - но обычные сайты (YouTube, GitHub, поиск) должны открываться и работать нормально, раз движок Chromium.

## Цели (выбор Алексея)
- **Красивый дизайн:** стиль Liquid Glass как в Хабе и калькуляторах, темы Paint (светлая/тёмная/цветные).
- **Без рекламы и слежки:** встроенная блокировка рекламы и трекеров по открытым спискам фильтров; **счётчик блокировок**
  на сайте (сколько рекламы и трекеров убрано).
- Вкладки, адресная строка с поиском, **закладки и история** (поиск по истории), **загрузки** (свой список; файлы ложатся
  в «Загрузки», дальше работает «Сортировщик загрузок»), **импорт закладок и истории из Chrome** одной кнопкой.

## Не цели
- Синхронизация между устройствами, расширения Chrome Web Store, свой движок рендеринга.
- Быть браузером по умолчанию (можно позже, если витрина понравится).

## Анти-цели
- Красивая оболочка, в которой обычные сайты ломаются или тормозят.
- Блокировщик, который ломает сайты без возможности выключить его на сайте.
- Любая отправка данных пользователя куда-либо (история, закладки - только локально).

## Решения Claude (можно поправить)
- Electron (Chromium внутри), интерфейс своими средствами (как Хаб), вкладки - WebContentsView.
- Блокировка: открытые списки фильтров (EasyList/EasyPrivacy) через проверенную библиотеку для Electron, обновление списков
  раз в неделю; выключатель «на этом сайте».
- Стартовая страница: быстрые ссылки (в том числе на Хаб и проекты Алексея), часы, фон в стиле Liquid Glass.
- Языки RU/EN, установка через InstallAll и release.ps1, выпуск на GitHub, тесты без видимых окон.

## Что остаётся строителю
Устройство вкладок и процессов, хранение (SQLite/JSON), формат импорта Chrome (закладки - JSON-файл профиля, история - SQLite,
читать копию, Chrome может быть открыт), набор законов (блокировка на тестовой странице, импорт на образце профиля, вкладки).
