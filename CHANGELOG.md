# Changelog / Журнал изменений

## 0.1.0 - not released / не выпущено

- First version of the showcase browser: Electron 44 (Chromium 152), tabs on WebContentsView, its own Liquid Glass interface with the five Paint themes (Glass, Formal, Light, Night, Warm), Russian and English. / Первая версия браузера-витрины: Electron 44 (Chromium 152), вкладки на WebContentsView, свой интерфейс Liquid Glass с пятью темами Paint («Стеклянная», «Строгая», «Светлая», «Ночная», «Тёплая»), русский и английский.
- Address bar: address or search by laws, six search engines, suggestions only from local history and bookmarks. / Адресная строка: адрес или поиск по законам, шесть поисковиков, подсказки только из своей истории и закладок.
- Ad and tracker blocking by EasyList and EasyPrivacy (Ghostery engine), a per-page counter, a per-site switch, hidden ad spaces, weekly list updates with a fallback mirror and a built-in short list. / Блокировка рекламы и трекеров по EasyList и EasyPrivacy (движок Ghostery), счётчик на странице, выключатель на сайте, скрытие пустых мест, недельное обновление списков с запасным зеркалом и встроенным коротким списком.
- Bookmarks (bar, folders, page), history with search, downloads to the Downloads folder with their own list, import of bookmarks and history from Chrome with one button (read-only copy). / Закладки (панель, папки, страница), история с поиском, загрузки в папку «Загрузки» со своим списком, импорт закладок и истории из Chrome одной кнопкой (копия, только чтение).
- Nothing leaves the computer: one local SQLite profile, strict CSP on internal pages, no server suggestions, no background services, a User-Agent without "Electron". / Ничего не уходит наружу: один локальный профиль SQLite, строгий CSP у своих страниц, без подсказок с сервера и фоновых служб, строка браузера без «Electron».
- Laws: core invariants on random inputs with a seed, branch coverage gates (core ≥ 90 %, windowless code ≥ 80 %), window laws in invisible Electron with a recording proxy, readability and overlap laws for all themes, memory laws, mutants. / Законы: инварианты ядра на случайных входах с зерном, пороги покрытия ветвей (ядро ≥ 90 %, код без окон ≥ 80 %), законы окна в невидимом Electron с записывающим прокси, законы читаемости и наложений для всех тем, законы памяти, мутанты.
- Windows installer config (electron-builder: NSIS + portable). / Конфиг установщика для Windows (electron-builder: NSIS + portable).
